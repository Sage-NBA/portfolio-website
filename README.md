## 📌 Overview

This project was built to present developer background, projects, and contact avenues with responsive layouts and fast client-side performance.

---

## ✨ Features

- 📱 **Mobile-Responsive**: Clean responsive navigation and hero sections.
- ⚡ **Lightning Fast**: Powered by Vite and React for instant page loads.
- 🎨 **Utility-First Styling**: Built with Tailwind CSS for consistent spacing and styling.

---

## 🛠️ Tech Stack

- **Framework**: [React](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Deployment**: [Vercel](https://vercel.com/)
- **Build Tool**: [Vite](https://vitejs.dev/)

---

## 🚀 Getting Started

```bash
git clone https://github.com/Sage-NBA/portfolio-website.git
cd portfolio-website
npm install
npm run dev
```
